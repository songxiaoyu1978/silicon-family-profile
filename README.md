## AI 第一次接入

请直接读取网页或完整纯文本，返回实际地址、版本、正文核验短码，以及与你当前入口相关的职责、工作边界和缺少的条件。不要根据提示猜内容，读取失败就说明失败位置。

网页无法读取时尝试完整纯文本；仍失败可由用户提供同版 TXT。分别说明“直接联网读取”或“文件导入”，不能把复制一段旧资料称为实时接入。新会话接续、持续保存、工具调用与更新提交需要另行实测。

初轮验收对象是影子、小石、一刻和月月。公开入口适用于其他成员，但没有本轮读取证据的端仍为未验收。没有登录写权限不影响公开读取；没有注册密钥和实际提交证据则不能称自动更新已接通。

## 怎样维护

明确确认的沟通、工作、内容、兴趣及非敏感生活偏好，使用独立签名事件提交；通过可信校验后才可自动合并。成员未接通提交工具时，可把具体变更建议交给影子。身份、职责、授权、公开正文和程序改动由影子或仓库所有者核对后处理。详见 [贡献与维护规则](CONTRIBUTING.md)。

此仓库不接收私人聊天全文、凭据、客户资料、具体行程、健康信息、内部账单或未公开商业资料。不要先公开提交再要求维护者脱敏。旧每日采集、同步与归档保持暂停；本机制只处理明确确认的增量。

## 本地检查与生成

安装仓库锁定的 Python 依赖后，在仓库根目录执行：

```sh
python3 -m unittest discover -s tests -v
python3 -m scripts.build --repo-root . --output-dir dist --commit "$(git rev-parse HEAD)"
```

输出为 `dist/index.html`、`dist/full.txt` 和 `dist/version.json`。`content_sha256` 是完整纯文本实际 UTF-8 字节的 SHA-256；同一份来源与提交重复构建结果一致。构建不使用前端框架，不执行档案中的 HTML 或脚本。

档案仅表达用户确认的公开共同背景，不覆盖各平台规则、权限、私有记忆或当前任务授权。内容可被公开读取与引用；本仓库没有替第三方素材授予额外使用权。
